### Standard Format Example

**Standard ID**: ACC-001
**Title**: Color Contrast Ratio
**Requirement**: Text must meet WCAG AA contrast ratios (4.5:1 for normal text, 3:1 for large text)
**WCAG Level**: AA
**Evaluation Criteria**:
- Measure contrast between text and background
- Check all text sizes
- Verify interactive elements meet 3:1 ratio

**Standard ID**: ACC-002
**Title**: Keyboard Navigation
**Requirement**: All interactive elements must be keyboard accessible
**WCAG Level**: A
**Evaluation Criteria**:
- Tab order is logical
- Focus indicators are visible
- No keyboard traps
- All actions available via keyboard

**Standard ID**: ACC-003
**Title**: ARIA Labels
**Requirement**: Interactive elements must have accessible names
**WCAG Level**: A
**Evaluation Criteria**:
- Buttons have aria-label or visible text
- Form inputs have associated labels
- Icons have descriptive labels
