# User Assistance Checklist

Quick reference checklist for evaluating User Assistance in Figma designs.

## Contextual Help

- [ ] Help icons present for complex features
- [ ] Tooltips defined for all interactive elements
- [ ] Help text is clear and concise
- [ ] Quick info links available where appropriate
- [ ] Context-sensitive help indicators present

## Input Guidance

- [ ] Form fields have labels
- [ ] Placeholder text provides examples
- [ ] Required fields are marked
- [ ] Field validation rules are visible
- [ ] Input format hints provided (e.g., date format)

## Error Handling

- [ ] Error messages are designed
- [ ] Error messages are specific and actionable
- [ ] Error state styling is clear
- [ ] Recovery steps are provided
- [ ] Inline validation feedback shown

## Success & Confirmation

- [ ] Success messages designed
- [ ] Confirmation dialogs present for destructive actions
- [ ] Progress indicators for long operations
- [ ] Completion feedback provided

## Onboarding & Discovery

- [ ] First-time user guidance considered
- [ ] Feature discovery elements present
- [ ] Walkthroughs or tours designed (if applicable)
- [ ] Tooltips for new features
- [ ] Empty states provide guidance

## Information Architecture

- [ ] Content hierarchy is clear
- [ ] Information is grouped logically
- [ ] Progressive disclosure used appropriately
- [ ] No overwhelming information density

## Microcopy

- [ ] Button labels are action-oriented
- [ ] Link text is descriptive
- [ ] Messages use appropriate tone
- [ ] Technical jargon avoided
- [ ] Consistent terminology throughout

## Help Resources

- [ ] Links to documentation visible
- [ ] Contact support options available
- [ ] FAQ or help center access provided
- [ ] In-app guidance resources linked

---

**Note**: This is a general checklist. Update with specific requirements from `./standards/user-assistance.md` once populated.
