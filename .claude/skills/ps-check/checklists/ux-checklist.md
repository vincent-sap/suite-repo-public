# UX Consistency Checklist

Quick reference checklist for evaluating UX consistency in Figma designs.

## Component Usage

- [ ] All components use SAP Fiori design system elements
- [ ] Components are used consistently throughout the design
- [ ] Component variants match approved patterns
- [ ] No custom components without documented exceptions
- [ ] Component states (hover, active, disabled) are defined

## Visual Design

### Colors
- [ ] Brand colors used correctly
- [ ] Semantic colors for states (error, success, warning, info)
- [ ] Color palette matches Fiori guidelines
- [ ] No unapproved custom colors

### Typography
- [ ] Font family matches Fiori standards (72 font family)
- [ ] Font sizes follow type scale
- [ ] Line heights are appropriate
- [ ] Text hierarchy is clear
- [ ] Font weights used correctly

### Spacing & Layout
- [ ] Consistent spacing between elements
- [ ] Grid system followed
- [ ] Padding and margins match Fiori specifications
- [ ] Alignment is consistent
- [ ] White space used effectively

## Navigation & Patterns

- [ ] Navigation patterns match Fiori guidelines
- [ ] Breadcrumbs used appropriately
- [ ] Back navigation available when needed
- [ ] Tab navigation follows conventions
- [ ] Page layouts match standard patterns (List Report, Object Page, etc.)

## Interaction Design

- [ ] Button styles used correctly (primary, secondary, tertiary)
- [ ] Interactive elements have clear affordances
- [ ] Loading states defined
- [ ] Empty states designed
- [ ] Confirmation dialogs follow patterns

## Icons & Graphics

- [ ] Icons from SAP icon font
- [ ] Icon sizes appropriate
- [ ] Icon usage consistent with meaning
- [ ] Graphics support the content

## Responsiveness

- [ ] Design considers different screen sizes
- [ ] Breakpoints defined
- [ ] Content reflows appropriately
- [ ] Mobile considerations addressed

---

**Note**: This is a general checklist. Update with specific requirements from `./standards/ux-consistency.md` once populated.
